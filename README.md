# 縦スクロール シューティングゲーム（仮称）

Webブラウザで遊べる、クラシックな縦スクロール・シューティングゲームです。
自機を操作して敵を撃ち落とし、道中を抜けてボスを倒すのが目標です。

> このREADMEは「企画の設計図」です。開発中はここを見れば、何を・どこまで・どう作るかが分かるようにしています。
> 専門用語には *(かんたんな説明)* を添えています。

---

## 🎮 どんなゲーム？

- 画面が下から上へ流れていく（＝縦スクロール）中で、自機が敵と弾を避けながら進みます。
- 敵を倒すとアイテムが出て、自機のショットがどんどん強くなります。
- 道中の最後に**ボス**が待ち受けていて、倒せばクリアです。
- ライフがゼロになるとゲームオーバー。ハイスコアはブラウザに記録されます。

操作はキーボードのみ：
- **移動**：矢印キー（または WASD）
- **ショット**：Z または スペースキー

## 📋 v1（最初の完成版）でつくるもの

最初のゴールを欲張らず、「始まり・道中・ボス・終わり」が揃った**1ステージ**を完成させます。

| 項目 | 決めたこと |
|---|---|
| 操作 | キーボード専用（移動＋ショット） |
| ジャンル | クラシックな縦シュー（弾は数十発レベル。弾幕ゲーではない） |
| ボリューム | 1ステージ＋道中＋ボス1体 |
| 自機のやられ | 残機制（ライフ3）。被弾で1機減り、しばらく無敵で復活。0でゲームオーバー |
| パワーアップ | 敵を倒すと出るアイテムでショットが段階的に強化。被弾すると1段階ダウン |
| 見た目 | まずは図形（四角・三角・円）だけで描画。あとから絵に差し替え可能 |
| 音 | 効果音のみ（ショット・爆発・被弾）。BGMは余裕があれば追加 |
| 画面 | 縦長の固定サイズ（480×640）。ウィンドウに合わせて拡大表示 |
| 画面の流れ | タイトル → ゲーム → クリア／ゲームオーバー → タイトルへ戻る |
| スコア | プレイ中にスコア表示。ハイスコアはブラウザに保存（次回も残る） |

### v1ではやらないこと（将来のアップデートで追加）
- スマホ／タッチ操作対応
- 弾幕（画面いっぱいの弾）
- 2ステージ目以降
- ボム（緊急回避技）
- BGM、本格的な絵（スプライト）
- オンラインのランキング機能（別途サーバーが必要なため）

> 👉 **ボスの攻撃パターン・難易度・目標プレイ時間などは、v1を動かしながら少しずつ詰めていきます。**

## 🛠 使っている技術（と、その理由）

非エンジニア向けに、それぞれ「何のためのものか」を添えます。

| 技術 | 何のもの？ | なぜ選んだか |
|---|---|---|
| **TypeScript** | プログラミング言語。JavaScriptに「型」という安全装置を足したもの | 間違いをコードを書いた時点で気づきやすく、バグが減る |
| **Canvas 2D** | ブラウザに絵を描くための標準機能 | ゲームの仕組みを自分で作れて、技術力のアピールになる。軽い |
| **Vite** *(ヴィート)* | 開発を快適にする道具。保存すると即画面に反映される | 設定がほぼ不要で、公開用ファイルもワンコマンドで作れる |
| **GitHub** | コードを保存・公開する場所 | 作品のコードをそのまま見せられる |
| **GitHub Pages** | GitHubが無料で提供するWeb公開機能 | リポジトリと公開URLが一体。お金がかからない |

## 🧱 ゲームの中身の設計（技術メモ）

開発を進めるときの土台になる方針です。

- **ゲームループ**：「固定タイムステップ」方式を採用。
  *(どんな性能のPCでも、弾の速さや動きが同じ手触りになる仕組み。環境によって速くなったり遅くなったりしない)*
- **当たり判定**：円どうしの距離で判定。自機の当たり判定は見た目より少し小さくして、ギリギリ避けられる気持ちよさを出す。
- **敵の出現**：「何秒後に・どの敵を・どこに出すか」を一覧データとして持つ。
  *(プログラムの本体をいじらず、数値の調整だけで難易度を変えられる)*
- **画面の状態管理**：`タイトル / プレイ中 / ゲームオーバー` の3つの状態を切り替えて動かす。

## 🚀 開発・公開のしかた（はじめての人向け手順）

### 0. 準備：Node.js を入れる
このゲームの開発には **Node.js** *(JavaScriptを動かす土台ソフト)* が必要です。
[https://nodejs.org/](https://nodejs.org/) から「LTS版」をダウンロードしてインストールしてください。

インストールできたか確認（ターミナルで実行）：
```bash
node -v
```
バージョン番号（例：`v20.x.x`）が表示されればOKです。

### 1. このプロジェクトを動かす
プロジェクトのフォルダ内で、ターミナルから以下を順に実行します。

```bash
# 必要な部品をダウンロード（最初の1回だけ）
npm install

# 開発用サーバーを起動（保存すると自動で画面に反映される）
npm run dev
```
表示されたURL（例：`http://localhost:5173`）をブラウザで開くとゲームが動きます。
止めるときはターミナルで `Ctrl + C`。

### 2. 公開用ファイルを作る
```bash
npm run build
```
`dist` というフォルダに、Webに置けば動く形のファイル一式ができます。

### 3. Webで公開する
GitHubにアップロードし、GitHub Pages を有効にすると、誰でも遊べるURLが手に入ります。
（この手順は、開発が進んだ段階で改めて一緒に進めましょう。）

## 🌳 つくる順番（ロードマップ）

上から順に作っていきます。各ステップが終わるたびに区切りを保存（コミット）します。

1. **土台**：プロジェクトを用意し、画面とゲームループだけ動かす
2. **自機**：キーボードで動かす → ショットを撃つ
3. **敵と当たり判定**：雑魚敵を1種類出し、自弾で壊せるようにする
4. **道中**：データに沿って敵が次々スクロール出現する
5. **自機のやられ**：残機・無敵時間・ゲームオーバー
6. **パワーアップ**：アイテム・段階強化・被弾でダウン
7. **ボス**：体力と攻撃パターン、倒したらクリア
8. **ガワ**：タイトル画面・リザルト画面・ハイスコア保存
9. **仕上げ**：効果音や爆発エフェクト
10. **公開**：自動で公開される仕組みを整える

## 📝 Gitの使い方メモ（このプロジェクトのルール）

- 1人開発なので、難しいことはせず `main` に直接コミットしていきます。
- コミットの説明は短く分かりやすく。先頭に種類をつけます：
  - `feat:` 新しい機能（例：`feat: 自機の移動を実装`）
  - `fix:` 不具合の修正（例：`fix: 弾が画面外で消えない問題を修正`）
- `node_modules` と `dist` フォルダは記録しません（自動生成されるため。`.gitignore`で除外）。
